# Лайм-тек — дизайн DiDi-shop

Утверждён владельцем 2026-10-22. Источник — холст Claude Design «DiDi-shop — варианты стиля», артборд «A · Лайм-тек» (исходник: `mockup.dc.html` в этой папке).

Файлы:
- `tokens.json` — **единственный источник значений**: цвета светлой и тёмной темы, тени, радиусы, отступы, шрифты, параметры анимаций. В коде клиентов значения берутся отсюда, а не подбираются заново. Код генерируется: `python3 scripts/gen_tokens.py` → `mobile/src/theme/tokens.ts` (приложение) и `tokens.css` (веб-витрина); CI проверяет актуальность и контраст.
- `tokens.css` — CSS-переменные обеих тем (генерируется, не править).
- `mockup.dc.html` — исходник интерактивного макета (формат Claude Design: шаблон `{{…}}` + класс `Component`). Запускается только в Claude Design; в проекте — эталон поведения и CSS (тени, переходы, сворачивание шапки).

## Настроение
Современно, просто, ярко, солнечно-зелёная гамма, хайтек. Светлый фон, белые карточки, «оторванные» от фона многослойной тенью. Лаймовый акцент `#C6F432` на почти чёрном зелёном `#13261C`. Тёмная тема — такая же объёмная: карточки светлее фона, диагональный перелив, светлая кромка сверху, тёмный нижний край, глубокая тень и слабое лаймовое свечение.

## Экран каталога

**Шапка (стекло, поверх ленты)**
- Развёрнута (лента вверху): логотип `Di` (плашка 44, `brand`/`brandInk`) + двухстрочное название — подпись «Доставка сегодня» (`muted`, 12) и `DiDi-shop` (Unbounded 24, «-shop» цветом `brand`); справа — тема (луна/солнце) и корзина со счётчиком (лаймовый бейдж); ниже поле поиска (52, кнопка фильтров — лаймовая плашка 40) и сегменты категорий (40, активный — `segOnBg`/`segOnInk`).
- Свёрнута (прокрутка > 24 px, обратно < 8 px — гистерезис): подпись, поиск и категории уходят (высота → 0, прозрачность, сдвиг −10 px, масштаб .96), название → 16 px, кнопки → 38 px, отступ сверху 42, снизу 8; справа появляется лаймовая кнопка поиска — по нажатию лента плавно прокручивается наверх и шапка раскрывается.
- Фон шапки — `glass` + blur 22 + saturate 180%; в свёрнутом виде — тень `header` и кромка `glassLine`.
- **Лента растворяется под шапкой**: маска сверху (развёрнута: прозрачно до 110 px → непрозрачно с 236 px; свёрнута: 30 → 92 px).

**Лента товаров** — сетка 2 колонки, отступы по краям 10, зазор 10. Карточка: радиус 26, внутренний отступ 6, фон `card`, тень `card`; плашка фото 214 px, радиус 21, `imageInset`; бейдж скидки (`segOnBg`/`segOnInk`) слева сверху; название Manrope 15/700; цена Unbounded 17 + старая цена зачёркнута (`strike`). Нажатие — масштаб .96. Над сеткой — заголовок раздела (надзаголовок 12 caps + Unbounded 28).

**Нижняя панель** — плавающая (отступы 16, снизу 22), высота 70, радиус 26, фон `nav` (тёмная в обеих темах). Активная вкладка шире (132, с версии 1.1.1; было 120) и показывает подпись, остальные — только иконка; лаймовая капсула переезжает за 400 мс. Вкладки: Каталог, Контакты, Корзина, Профиль (с сессии 9; поиск — из шапки каталога).

## Карточка товара
- Открывается снизу (сдвиг 102 % → 0 за 420 мс), каталог позади уменьшается (.93), бледнеет (.35) и размывается.
- Фото-«герой» 420 px с отступом 12, радиус 32, вырастает из .9; поверх — стеклянные кнопки «Назад» и «В избранное» (48), индикатор галереи.
- Ниже по очереди проявляются (задержки 120/180/240/300 мс): категория-тег + название (Unbounded 23) + цена (24); размеры (кнопки 56×48, выбранный — лаймовый с подсветкой); описание; кнопка «В корзину» (62, радиус 22, цена справа).
- «В корзину»: лаймовая заливка слева направо за 550 мс, текст → «Добавлено в корзину», счётчик корзины +1.

## Тёмная тема
Переключатель в шапке (и системная тема по умолчанию — уточняется в сессии 8). Все цвета — переменные темы, смена анимируется 450 мс. Плашки фото — тёмные варианты тонов (`productTones[*][1]`), кнопка «В корзину» лаймовая.

## Доступность
- Касание ≥ 44 px; иконочные кнопки с `aria-label` / `accessibilityLabel`.
- Контраст текста ≥ 4.5:1 в обеих темах (`muted` проверен на `bg` и `card`).
- «Уменьшить движение» в системе → переходы заменяются на fade ≤ 150 мс, без размытия и масштаба.

## Перенос в код (сессия 8)
- React Native (Expo SDK 57): многослойные тени — стиль `boxShadow` (строка CSS, несколько слоёв, включая `inset`; новая архитектура RN); стекло — `expo-blur`; маска ленты — `@react-native-masked-view/masked-view` + `expo-linear-gradient` (или градиентная подложка, если маска дорогая на Android); анимации — `react-native-reanimated` (`useAnimatedScrollHandler` для шапки, `entering` с задержками для карточки товара, `withTiming` с теми же кривыми); шрифты — `@expo-google-fonts/unbounded` и `@expo-google-fonts/manrope`.
- Веб-витрина (сессия 9): CSS-переменные один в один из `tokens.json` (как в `mockup.dc.html`), `prefers-color-scheme` + переключатель.
- Фото товаров заменяют плашки-заглушки; тон плашки остаётся подложкой при загрузке.

## Версия 1.1 и решения сессии 8 (2026-10-22)
- **Семантические цвета** (обе темы): `border`, `inputLine`, `neutral`/`neutralBg`, `danger`/`dangerBg`, `success`/`successBg`, `warning`/`warningBg`, `info`/`infoBg` — формы, сообщения, статусы заказа (ожидает оплаты — warning, оплачен/собран — tag, в пути/готов к выдаче — info, доставлен — success, отменён — neutral). Контраст текста на своём фоне ≥ 4.5:1 (проверяет `gen_tokens.py --check`).
- **Тема по умолчанию — системная**; кнопка в шапке переключает явно, в профиле — «Как в системе / Светлая / Тёмная».
- **Подпись «Доставка сегодня» убрана** — в шапке только логотип и название.
- **«В избранное» убрано** до появления функции.
- **Тон плашки фото** — по товару автоматически (хэш slug → один из 6 тонов `productTones`), без поля в БД.
- **Растворение ленты** — градиентная подложка цвета фона под шапкой (вместо маски: дешевле на Android, одинаково в браузере).
- **Стекло шапки** — blur на iOS и в браузере; на Android — полупрозрачный `glass` без размытия (производительность).
- **Карточка товара** — лист снизу поверх вкладок; каталог позади уменьшается и бледнеет без размытия (размытие на Android дорогое).
- **Вкладка «Поиск»** — отдельный экран: поле с фокусом, категории, сортировка, цена, «В наличии». Кнопка фильтров в шапке каталога открывает её с раскрытыми фильтрами.
- **Иконки приложения** — «Di» Unbounded Bold, лайм на `ink` (`scripts/make_icons.py`).
